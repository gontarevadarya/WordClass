# СловоКласс

Полноценный сайт (Next.js) для занятий английским.

**Структура:**
- **Учитель** входит по общему паролю (`TEACHER_PASSWORD`) на `/login` и
  управляет всеми учениками на странице «Мои ученики» (`/students`).
- У каждого ученика — своя личная **папка (пространство)**, доступная по
  **личному PIN-коду** (генерируется автоматически, учитель может посмотреть
  и перевыпустить его в любой момент).
- Внутри пространства ученика:
  - **Папки со словами** — создаёт и редактирует только учитель (текст,
    картинки с Unsplash, произношение). Ученик их видит и учит, но не может
    менять.
  - **Папки с заданиями** — полностью в руках ученика: он сам создаёт папки,
    пишет/редактирует/удаляет в них что угодно (заметки, ответы, тренировки)
    в свободном текстовом поле с автосохранением.
  - **Задание «соотнеси слово с картинкой»** собирается автоматически из
    папки со словами; результат публикуется от имени вошедшего ученика одной
    кнопкой (имя вводить не нужно — оно уже известно из PIN-сессии).

В отличие от прототипа-артефакта в чате, здесь:
- секретные ключи (Unsplash, Anthropic) хранятся только на сервере и никогда
  не попадают в браузер;
- вход учителя и каждого ученика — через настоящий пароль/PIN и подписанную
  cookie-сессию (у каждой роли — свой независимый вход);
- данные хранятся в настоящей базе (Redis), а не во временном хранилище чата.

## Что понадобится (всё бесплатно для такого объёма использования)

1. Аккаунт на [github.com](https://github.com) — чтобы разместить код.
2. Аккаунт на [vercel.com](https://vercel.com) — чтобы сайт был опубликован
   (можно войти через GitHub, отдельная регистрация не нужна).
3. Access key от Unsplash (Settings → Developers → Your apps) — он у вас уже есть.
4. Придуманный вами пароль учителя и любая случайная длинная строка для
   SESSION_SECRET (можно просто настучать по клавиатуре 30-40 случайных
   символов).
5. (Необязательно) ключ Anthropic API с [console.anthropic.com](https://console.anthropic.com)
   — только если хотите, чтобы кнопки «Подобрать картинки (анализ слова ИИ)»
   и «Перевести автоматически» работали. Без него сайт полностью
   работоспособен: картинки ищутся по самому слову, перевод вводится вручную.
   С ключом запросы к Anthropic платные (обычно копейки при таком объёме).

## Шаг 1. Загрузить код на GitHub

1. Зайдите на github.com → New repository → дайте название, например
   `wordclass` → Create repository.
2. На странице пустого репозитория нажмите «uploading an existing file» и
   перетащите туда содержимое этой папки (кроме `node_modules` и `.next`,
   если они есть — обычно их и не будет в скачанном архиве).
3. Commit changes.

## Шаг 2. Опубликовать на Vercel

1. Зайдите на vercel.com → Add New → Project → войдите через GitHub → выберите
   репозиторий `wordclass` → Import.
2. Framework Preset определится сам как Next.js — ничего менять не нужно.
3. Разверните блок **Environment Variables** и добавьте:
   - `TEACHER_PASSWORD` — ваш пароль для входа как учитель
   - `SESSION_SECRET` — любая длинная случайная строка
   - `UNSPLASH_ACCESS_KEY` — ваш access key из Unsplash
   - `ANTHROPIC_API_KEY` — необязательно, см. выше
4. Нажмите **Deploy** и подождите 1-2 минуты.

## Шаг 3. Подключить хранилище данных (Redis)

Без этого шага сайт откроется, но папки не будут сохраняться.

1. В панели проекта на Vercel откройте вкладку **Storage**.
2. Create Database → выберите **Redis** (через маркетплейс, обычно от Upstash,
   есть бесплатный план).
3. После создания нажмите **Connect Project** и выберите ваш проект
   `wordclass` — Vercel сам добавит нужные переменные окружения
   (`KV_REST_API_URL`, `KV_REST_API_TOKEN`).
4. Откройте вкладку **Deployments** и нажмите «Redeploy» на последнем
   деплое, чтобы новые переменные подхватились.

## Готово

Сайт будет доступен по адресу вида `https://wordclass-ваш-ник.vercel.app` —
это и есть та самая открытая ссылка. Она одна для всех: и для вас, и для
учеников, различие только в том, как вы входите.

**Первые шаги:**
1. Откройте сайт → «Я учитель» → войдите паролем из `TEACHER_PASSWORD`.
2. «Мои ученики» → добавьте ученика по имени — сайт сам сгенерирует ему PIN.
   Скопируйте PIN и сообщите ученику (лично, не через общий чат класса).
3. У этого ученика откройте «Папки со словами» → создайте папку → добавьте
   слова с картинками и произношением.
4. Ученик заходит на тот же адрес сайта → «У меня есть PIN» → вводит свой
   код → попадает только в своё пространство, видит папки со словами (может
   учить и проходить задание) и создаёт свои папки с заданиями.

## Проще: попросите Claude Code сделать это за вас

Если не хочется проделывать шаги 1-3 руками, можно открыть эту папку в
Claude Code (или в приложении Claude Desktop → вкладка Code) и попросить:
«разверни этот проект на Vercel и настрой переменные окружения» — агент
умеет выполнять команды git/vercel сам, вам останется только ввести пароль
учителя, SESSION_SECRET и ключ Unsplash, когда он спросит.

## Локальный запуск для проверки (необязательно)

```bash
npm install
cp .env.example .env.local   # впишите туда свои значения
npm run dev
```

Откроется на http://localhost:3000. Для работы понадобится тот же Redis —
проще всего создать его сначала на Vercel (шаг 3) и скопировать его
KV_REST_API_URL / KV_REST_API_TOKEN в `.env.local`.
